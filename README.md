# Simon Says Game

A browser-based Simon Says memory game built using HTML, CSS, and JavaScript.

## Features

- Random color sequence generation
- User input validation
- Increasing difficulty with each level
- Score/level tracking
- Game over screen with restart option

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Play

1. Press any key to start the game.
2. Watch the color sequence carefully.
3. Repeat the sequence by clicking the buttons.
4. The sequence gets longer after every correct round.
5. The game ends when you click the wrong button.
